# Criticos App

Esta aplicación permite registrar cables por terminarse en el punto de uso de la línea (desde móvil) y dar seguimiento a esos registros desde escritorio. Construida con React y Vite, lista para funcionar como PWA y para agregar backend.

## Instalación y uso

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Ejecuta la app en modo desarrollo:
   ```bash
   npm run dev
   ```
